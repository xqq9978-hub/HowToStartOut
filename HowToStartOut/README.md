# 新人保护指南 · HowToStartOut

![新人保护指南封面：毕业第一年，没人教你的事](assets/cover.png)

收到第一份 offer，怎么核对合同、试用期与工资？第一次租房、发薪和交付工作时，怎样问清楚、留下记录、找到能核对的依据？这份指南面向中国大陆毕业生与初入职场者，按生活场景整理成 **14 章、附录 A—K**，可以只读眼前需要的一节。

> 这是一份查阅与自查材料。政策和办事条件可能因地区、时间与个人情况变化；涉及权益、健康与财务的决定，请核对现行官方原文和适用条件。不要把身份证号、完整合同、工资流水等敏感材料贴到公开 issue 或 AI 对话中。

## 使用新人保护助手

Skill 支持 **INIT / CHECK / HELP / PLAN** 四种模式。CHECK 默认每轮 5 题，支持批量回答、跳过已知事项、针对性追问，并在信息足够时提前给出阶段性风险报告；具体判断依赖随包提供的 V6 知识库，政策与法律结论仍须核验现行来源。

下载仓库后，将 [`skills/newcomer-protection-assistant/`](skills/newcomer-protection-assistant/) **整个文件夹**复制到 Codex 的 `~/.codex/skills/`（若设置了 `CODEX_HOME`，使用其中的 `skills/`）。保留 `SKILL.md` 与 `references/新人保护指南-V6.md` 的相对位置。你也可以直接把两份文件提供给其他支持自定义 Skill 的助手，并按其产品要求安装。

可以这样开始：

```text
新人保护助手 CHECK：我下周入职。请每轮最多问 5 题，已知的信息不要重复问；足够判断时直接给阶段性报告。
```
