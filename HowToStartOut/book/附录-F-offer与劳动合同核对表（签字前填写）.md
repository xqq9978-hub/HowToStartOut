## F. offer与劳动合同核对表（签字前填写）

[↑ 回到目录](../README.md#guide-toc) · [按问题查](00-阅读入口.md#by-problem)

用途：把招聘承诺、签署文件和实际安排逐项对照。**“未说明”就写未说明，不靠猜测补齐；需要估算的金额单列假设与公式。**

| 核对项 | offer/招聘沟通写了什么 | 合同/附件写了什么 | 已确认的答复、凭证或待办 |
|---|---|---|---|
| 用人单位全称、统一社会信用代码 | 待填写 | 待填写 | 主体关系是否解释清楚 |
| 实际工作单位；直签、派遣、外包等安排 | 待填写 | 待填写 | 不能只看协议名称 |
| 岗位、职责、汇报对象 | 待填写 | 待填写 | 范围不同的先确认 |
| 工作地点、调动或远程安排 | 待填写 | 待填写 | 是否与预期一致 |
| 固定工资、绩效、提成、补贴 | 待填写 | 待填写 | 税前/税后、条件分别列 |
| 试用期工资与转正工资 | 待填写 | 待填写 | 不用转正工资代填试用期金额 |
| 发薪日、首笔工资到账时间 | 待填写 | 待填写 | 是否有不完整首月或延后发放 |
| 年终奖、奖金的适用条件 | 待填写 | 待填写 | 不把不确定奖金当成固定收入 |
| 合同期限、试用期与起止日 | 待填写 | 待填写 | 对照法定上限 |
| 录用、转正条件及确认方式 | 待填写 | 待填写 | 是否事先明确、如何核验 |
| 工时、休息、加班和值班 | 待填写 | 待填写 | 制度、审批及待遇分别问 |
| 社保缴纳地、起始月、基数 | 待填写 | 待填写 | 与公司注册地分开核实 |
| 公积金缴纳地、起始月、比例与基数 | 待填写 | 待填写 | 单位与个人分别记录 |
| 背调、体检、毕业资格等前置条件 | 待填写 | 待填写 | 哪些已完成、哪些仍待完成 |
| 服务期、培训、特殊待遇返还 | 待填写 | 待填写 | 触发条件与计算方法 |
| 保密、竞业、知识产权与兼职限制 | 待填写 | 待填写 | 范围、补偿、期限与例外 |
| 三方解约、入职前变更及相关责任 | 待填写 | 待填写 | 不与劳动合同违约金混用 |
| 附件、员工手册与制度版本 | 待填写 | 待填写 | 完整文件是否已取得 |
| 实际入职日、签署日、合同起始日 | 待填写 | 待填写 | 不同日期分别记，不签不实日期 |
| 其他签署文件 | 待填写 | 待填写 | 有无空白授权、预签辞职、结清或认责文件 |
| 本人留存方式 | 待填写 | 待填写 | 完整纸本或有效电子文本、附件、签署记录 |

核对人：待填写。核对日期：待填写。还没解决的关键问题：待填写。下一步联系谁、何时确认：待填写。

有争议时看[3.21](03-实习、入职与试用期.md#item-3-21)。这张表用于发现差异，不能替代对具体合同效力的判断。
