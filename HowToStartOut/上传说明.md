# 把 HowToStartOut 上传到 GitHub

1. 解压 `HowToStartOut-GitHub最终上传包.zip`。
2. 打开解压得到的 `HowToStartOut` 文件夹。上传的是**文件夹里面的全部内容**，包括 `.github`、`assets`、`book`、`docs`、`skills`、`tools` 和根目录文件；不要只挑 `README.md`、`SKILL.md` 等几个文件。
3. 如果仓库已经有旧版的四个根目录文件，请先在本地仓库中清理旧版 `cover.png`、根目录 `SKILL.md` 和根目录 `新人保护指南-V6.md`，再复制本包内容。新版本的封面位于 `assets/`，Skill 位于 `skills/newcomer-protection-assistant/`。
4. 使用 GitHub Desktop 提交并推送整个仓库目录，或用你熟悉的 Git 工具提交；保留上面的子目录结构。
5. 上传完成后，打开仓库首页，检查封面、章节链接和 Skill 链接能否打开。GitHub Actions 的 `Check guide package` 会检查分章文件与本地链接。

本包没有替你创建 GitHub 仓库、配置发布网站或选择开源许可证。仓库是否公开及如何授权，由你在 GitHub 上决定。
