## A. 求助电话速查

[↑ 回到目录](../README.md#guide-toc) · [按问题查](00-阅读入口.md#by-problem)

| 遇到什么事 | 打给谁 |
|---|---|
| 劳动合同、社保、工资、辞退 | 12333 人社服务热线 |
| 被骗、人身安全 | 110 |
| 反诈劝阻（接到一定要接） | 96110 |
| 情绪撑不住、需要心理支持 | 查本人所在地卫健部门公布的心理援助服务；核实服务时间和接入方式。有即时生命危险时联系120/110 |
| 租房纠纷、各类民生问题 | 12345 政务服务热线 |
| 消费纠纷 | 12315 |
| 需要免费法律帮助 | 12348 法律服务热线 |
| 求职性别歧视、孕期权益受侵害 | 12338 妇女维权热线 |
| 急救、有人突然倒下（见 7.10） | 120 |
| 手机丢了，先挂失手机卡（见 6.32） | 移动 10086 / 联通 10010 / 电信 10000 |
| 个税、离职补偿怎么交税（见 5.17） | 12366 纳税服务热线 |
| 医保报销、异地就医（见 7.7） | 12393 医保服务热线 |
| 公积金提取、贷款（见 6.12） | 12329 住房公积金热线 |

> 这些是面向中国大陆的常见服务入口。咨询受理范围与转接可能因地区不同；心理支持联系方式应按读者所在地单独核验，未核到适用信息时不猜号码。110、120用于相应紧急情况；普通咨询、投诉不保证立即解决问题。
