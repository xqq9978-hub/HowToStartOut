## H. 劳动争议材料清单与行动记录

[↑ 回到目录](../README.md#guide-toc) · [按问题查](00-阅读入口.md#by-problem)

用途：把“发生了什么、要什么、证据在哪”整理清楚。**投诉、咨询、协商与仲裁是不同程序；不要默认打过电话就已立案，或默认协商一定暂停法定期限。**

**先选眼前的一步**

1. 有人身危险或急症：先离开危险、联系相应急救或警方，不先整理表格。
2. 只是工资、规则或安排没解释清楚：向有权限的人发具体问题，保留答复；愿意协商的，写明待解决事项和答复期限。
3. 持续欠薪、违法解除或其他争议：查询劳动合同履行地、用人单位所在地等相关机构的受理规则，核对劳动监察、仲裁等渠道各自处理范围。劳动仲裁一般需先申请，不能把所有劳动争议直接当普通民事诉讼处理。
4. 需要正式提交：从主管部门公布的渠道取得材料清单或申请表，核实管辖、提交方式、是否受理及补正要求。仲裁不收案件受理费；律师、交通、取证等可能产生其他成本，符合条件时可咨询法律援助。

**一、主体和事实**

| 要整理什么 | 本人记录 |
|---|---|
| 本人联系方式；身份证明按机构要求提交 | 待填写，不把证件完整号码发公开平台 |
| 用人单位准确全称、地址和登记信息 | 待填写，派遣/多主体用工还列实际管理方 |
| 实际入职、合同期限、岗位、工作地点 | 待填写 |
| 约定工资、发薪日、实际发薪 | 待填写，固定与浮动部分分开 |
| 争议发生与得知日期、离职/解除日期 | 待填写，保留通知及送达材料 |
| 按日期列发生的事 | 每行写日期、谁、做了什么、原文件位置 |
| 希望解决什么 | 每项请求单列，不只写“我要维权” |
| 金额如何得出 | 列期间、基数、数量、公式、已付金额和来源；不确定项标待核实 |
| 适用时效或其他期限、咨询依据 | 待核实；工伤认定、仲裁、诉讼等分别算，不能共用一个“一年” |

**二、证据目录**

| 材料 | 想证明什么 | 文件位置与原始载体 |
|---|---|---|
| offer、合同、附件、员工手册版本 | 主体、条件、规则及告知情况 | 待填写 |
| 工资条、银行流水、合法报酬记录 | 约定及实际支付 | 待填写 |
| 社保公积金记录、个税记录 | 相关缴费和申报事实 | 待填写 |
| 考勤、排班、工作安排与审批 | 实际用工、出勤、加班等 | 待填写 |
| 催款、异议、解除通知及签收记录 | 请求、送达、解除或相关时间 | 待填写 |
| 原始聊天、邮件、本人参与的合法录音 | 具体沟通内容 | 待填写；不要只剩剪辑或局部截图 |
| 已付与未付金额明细 | 对应具体请求 | 待填写，区分事实金额和估算 |
| 其他直接相关材料 | 按实际需要写 | 待填写 |

只保存本人合法取得、与争议直接相关的材料。不越权下载、不批量转走商业秘密和无关个人数据；不把材料公开到社交平台。涉及保密内容时先咨询如何向有权机构提供。

**三、办理记录**

| 日期 | 联系机构/渠道 | 事项与提交材料 | 受理号/凭证 | 对方要求、下一步与期限 |
|---|---|---|---|---|
| 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |

咨询电话用于弄清办理路径，不代表自动受理。提交后保存回执，留意送达、补正、开庭和裁决后续期限。金额或法律依据拿不准时，如实标明，请专业人士核实，别用AI生成的法条或计算直接代替事实。

参见5.7—5.10及5.17；规则依据为[《劳动争议调解仲裁法》](https://www.mohrss.gov.cn/SYrlzyhshbzb/ztzl/ldrszytjzc/fgzc/202207/t20220714_457857.html)第5、21、27—29、53条等关于管辖、时效、申请与收费的规定，具体材料按受理机构要求准备。
