## B. 话术速查卡

[↑ 回到目录](../README.md#guide-toc) · [按问题查](00-阅读入口.md#by-problem)

| 场景 | 可以这样说 |
|---|---|
| 确认任务 | 「我复述一下：要做 ××，周四交初稿，对吗？」 |
| 忙不过来 | 「我手上有 A 和 B，接新任务的话 B 要推两天，您看哪个优先？」 |
| 做错了 | 「需要同步一个问题：××出错了，我已经 ××，以后会 ××。」 |
| 非值班、非紧急的下班消息 | 可以在下一工作时段回复；需要简短确认时说「明天上班后处理，预计上午十点给第一版」。先查值班安排（9.2） |
| 拒绝同事 | 「我这周手上比较满，这次帮不了，抱歉啊。」 |
| 拒绝喝酒 | 「我以茶代酒敬您，谢谢您的照顾。」 |
| 拒绝借钱 | 「我刚工作手头也紧，这次真的帮不上，抱歉。」 |
| 亲戚问工资 | 「够花，还在努力。您最近身体怎么样？」 |
| 问社保 | 「我查了社保记录，这个月好像还没缴，想确认一下是不是还在办理中？」 |
| 约转正沟通 | 「试用期快结束了，想约您 20 分钟聊聊我的表现和您的期待。」 |
| 要求很模糊 | 「我先按我的理解做个小样，半天后给您看方向，对了再往下做。」 |
| 做不完 | 「按现在的进度周五做不完，我可以周五先交 A 部分，B 部分下周二交，您看行吗？」 |
| 催还钱 | 「上次借你的 ×× 元，我这个月要交房租，方便的话这周转我一下？」 |
| 被请求刷脸、担保 | 「刷脸、签字、担保这类事我一律不帮，跟信不信你没关系，是我自己的原则。」 |
| 不去聚会 | 「这次我就不去了，祝你们玩得开心。」不必为了拒绝而另许承诺。 |
| 视频里借钱 | 「我先挂了，回拨你原来的号码确认一下。」（然后真的挂断、回拨） |
| 接到口头 offer | 「麻烦把正式 offer 发到我邮箱，写上岗位、薪资和签约公司，我确认后尽快回复。」 |
| 问签约公司 | 「劳动合同是和哪家公司签？社保和公积金在哪个城市缴纳？」 |
| 谈加薪 | 「这一年我负责了 A 和 B，结果是 ××。下次调薪时，我的薪资能不能调到 ××？」 |
| 租房养宠物 | 「合同里加一条：允许养宠物，退租时我自己打扫干净，您确认后不另收清洁费。」 |
| 办预付卡 | 「我先买一个月试试。办年卡的话，中途不练了，剩下的钱怎么退？」 |
| 面试作业范围太大 | 「能否缩小为一个模块，或用已有作品讲解？请确认成果用途和试岗结算。」 |
| 被错误指责 | 「这个问题我会配合核对，有一点事实需要先澄清，我把记录一起发您。」 |
| 第一次就不方便帮忙 | 「我可以讲十分钟方法，但没有时间接手整份工作。」 |
| 要求签不实文件 | 「我不能确认与事实不符的内容，请先提供事实依据和完整文件。」 |
