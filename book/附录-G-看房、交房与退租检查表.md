## G. 看房、交房与退租检查表

[↑ 回到目录](../README.md#guide-toc) · [按问题查](00-阅读入口.md#by-problem)

**第一张：付款前的核验表**

| 项目 | 结果/凭证 | 有问题时的下一步 |
|---|---|---|
| 房屋地址、出租部分与产权信息 | 待填写 | 不清楚先不付定金或押金 |
| 出租方身份及有权出租的依据 | 待填写 | 产权人、授权代理、转租方分别核对 |
| 转租权限、主租约期限及相关限制 | 待填写/不适用 | 核实转租是否被允许，能否覆盖拟租期间 |
| 合同主体、收款账户和资金监管要求 | 待填写 | 区分经纪服务与企业转租，见4.10 |
| 租金、押金、中介费、服务费 | 待填写 | 金额、收款方、付款日期分别列 |
| 水电燃气、物业、网络及其他费用 | 待填写 | 计价性质、单价依据与承担方写清 |
| 租期、提前退租、续租、退押规则 | 待填写 | 扣款依据、交接和退款期限写清 |
| 通勤、噪声、通风与周边安全 | 待填写 | 结合早晚实际情况再看一次 |
| 居住登记或政策申请需要的配合 | 待填写 | 先确认所需材料与出租方意愿 |

**第二张：入住当天记录表**

| 区域或物品 | 状态/故障/读数 | 照片视频文件名 | 对方确认及处理日期 |
|---|---|---|---|
| 门锁、钥匙/门禁数量 | 待填写 | 待填写 | 待填写 |
| 墙面、地板、天花板、渗漏霉斑 | 待填写 | 待填写 | 待填写 |
| 水电燃气表起始读数 | 待填写，不适用的注明 | 待填写 | 待填写 |
| 卫生间、排水、水压 | 待填写 | 待填写 | 待填写 |
| 灶具、热水器、燃气设施及通风 | 待填写 | 待填写 | 安全疑问联系专业人员，不自行拆修 |
| 空调、冰箱、洗衣机和其他家电 | 待填写 | 待填写 | 待填写 |
| 家具、清洁和已有损坏 | 待填写 | 待填写 | 待填写 |
| 烟雾报警、楼道和逃生路径 | 待填写 | 待填写 | 堵塞、安全问题先处理 |

把记录发给合同相对方确认，保存完整消息和原文件；拍摄不夹带室友等无关隐私。空气质量有疑问时，按适用检测规范找合格机构，不以“没气味”或“通风够几个月”当作达标证明。

**第三张：退租交接与押金表**

| 项目 | 记录 |
|---|---|
| 通知退租方式、送达和约定交接日 | 待填写 |
| 合同约定扣款事项与实际争议 | 待填写；正常损耗、实际损坏分别记录 |
| 房屋终态、物品、钥匙、表读数 | 待填写，保留原始照片视频 |
| 已结算费用、依据、收款凭证 | 待填写 |
| 押金实付金额、拟退金额、扣款明细 | 待填写；不认可的写清具体事项 |
| 退款期限、账户与交接确认 | 待填写 |
| 催告、投诉、咨询和后续期限 | 待填写 |

不在还没核清楚时签“全部结清、无任何争议”。已有争议见4.18；紧急安全问题优先求助。
