# 新人保护指南 · HowToStartOut

![新人保护指南封面：毕业第一年，没人教你的事](assets/cover.png)

## 使用新人保护助手

Skill 支持 **INIT / CHECK / HELP / PLAN** 四种模式。针对你的具体问题，CHECK 和 HELP 最多分三轮提问，每轮不超过 5 题；支持批量回答、跳过已知事项，并在信息足够时提前给出带逐项核对卡的避坑报告。具体判断依赖随包提供的 V6 知识库，政策与法律结论仍须核验现行来源。

下载仓库后，将 [`skills/newcomer-protection-assistant/`](skills/newcomer-protection-assistant/) **整个文件夹**复制到 Codex 的 `~/.codex/skills/`（若设置了 `CODEX_HOME`，使用其中的 `skills/`）。保留 `SKILL.md` 与 `references/新人保护指南-V6.md` 的相对位置。你也可以直接把两份文件提供给其他支持自定义 Skill 的助手，并按其产品要求安装。

可以这样开始：

```text
新人保护助手 CHECK：我下周入职。请围绕我的情况最多问三轮，每轮不超过 5 题；已知信息不要重复问，最后给我能逐项核对的避坑报告。
```

## 内容与反馈

- [完整阅读版](docs/新人保护指南-完整阅读版.md)是面向读者的连续正文；`book/` 是由它拆出的分章阅读页，保持相同的条目编号。
- [`index.html`](index.html) 把正文与封面放进单个文件，双击即可离线阅读、搜索和切换章节；外部出处链接仍需联网才能打开。
- 修改连续阅读版后，可运行 `python3 tools/build_book.py` 与 `node tools/build_offline_html.mjs` 更新分章页和离线网页。HTML 生成器所用的第三方 Markdown 解析器及许可见 [`tools/vendor/`](tools/vendor/)；该许可不代表本指南的授权方式。
- [V6 原版知识库](skills/newcomer-protection-assistant/references/新人保护指南-V6.md)供 Skill 查证。它与用户提供的原版文件保持一致；阅读版的编辑增补不应被误写成 V6 原文。
- 发现具体问题，可用 [内容勘误模板](.github/ISSUE_TEMPLATE/内容勘误.md)提供条目编号、适用地区、问题和可核对的来源。请先去掉个人信息。
- 准备发布仓库时，先看[上传说明](上传说明.md)，保留所有子目录的层级。
